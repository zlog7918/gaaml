# Praca dyplomowa
Praca wykorzystuje szablon prac dyplomowych
na Wydziale Elektrycznym PW dostępny pod adresem
[https://github.com/SP5LMA/EE-dyplom](https://github.com/SP5LMA/EE-dyplom) autorstwa Łukasza Makowskiego.

Został nieznacznie zmieniony pod względem
działania plik `EE-dyplom.cls`.
Zmiany te zostały oznaczone komentarzem w pliku.
Komentarz zaczyna się od `zlog: `.

Dodatkowo zmieniony został folder `rysunki` na `img`.
